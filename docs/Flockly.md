# Flockly — главная

Telegram Mini App для организации встреч: организатор предлагает даты и места, участники голосуют,
приложение показывает итог. Бот — [@flocklyappbot](https://t.me/flocklyappbot) (short name `app`),
Mini App — `https://t.me/flocklyappbot/app`. Старый бот `@soberemsyabelarusbot` выведен из работы.

> Это хранилище Obsidian — папка `docs/` репозитория. Как открыть и синхронизировать —
> [Obsidian — как пользоваться](notes/Obsidian.md).
