# Журнал решений

Новые записи — сверху. Шаблон: `templates/Решение.md`. Подробные решения по этапам — в [ТЗ](../TZ.md).

## 2026-10-14 — Вкладка «Карта» и спокойная кнопка «+»
Выделенная кнопка «+» не по центру резала глаза. Добавили пятую вкладку «Карта» (сама карта — этап 4,
пока экран «скоро»), «+» встала по центру; кнопка без обводки и свечения, внутри панели.

## 2026-10-14 — Obsidian-хранилище в `docs/`
Документация проекта ведётся как хранилище Obsidian прямо в репозитории: заметки версионируются в git,
Claude обновляет их вместе с кодом. Ссылки — обычные markdown, чтобы читались и на GitHub.

## 2026-10-13 — Переезд на @flocklyappbot
Юзернейм старого бота сменить нельзя; данные привязаны к Telegram ID и сохраняются. Новое имя — Flockly
(у «Flock» в нише несколько приложений и знак в США).

## 2026-10-13 — Редизайн до этапа 2
Этап 2 добавляет много экранов; их дешевле сразу делать в новом дизайне. Выбран вариант А2 «Закат».

## 2026-10-13 — Уведомления: at-least-once
Никакого фиктивного exactly-once для Telegram: дубль возможен только при сбое между отправкой и отметкой.
Участники получают только важное; организатор выбирает «каждый ответ» или «сводку».

## 2026-10-13 — Своя аналитика вместо сторонних сервисов
`analytics_events` + экран «Статистика» и `/stats` только для администратора.
