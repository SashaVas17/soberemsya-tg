# Журнал решений

Новые записи — сверху. Шаблон: `templates/Решение.md`. Подробные решения по этапам — в [ТЗ](../TZ.md).

## 2026-10-14 — Этап 2.2: категории и поиск
Владелец согласовал список: кофе, бар, спорт, настолки, прогулка, кино, концерт, активный отдых (+ «другое»).
Категория необязательна (для встреч «по приглашению» она почти не нужна). Список — в таблице, а не в коде:
новая категория появляется без релиза (иконка — общая, пока не добавим свою). Поиск — только по названию
(`ILIKE`, «*» отбрасывается: PostgREST считает его шаблоном). Отложено: категория на экране встречи и её
смена в «Управлении», триграммный индекс для поиска (нужен, когда открытых встреч в городе станут сотни).

## 2026-10-14 — Этап 2.1: города
Один город на пользователя («ваш город»): по нему фильтруется лента открытых встреч, и в нём создаются
новые встречи. По умолчанию — Минск; выбор города при первом входе не нужен, пока открыт один город.
Часовой пояс берётся из города в ленте и превью открытой встречи; «Мои встречи», уведомления и статистика
пока в минском времени — все города Беларуси в нём, перевод — вместе с первым городом в другом поясе.

## 2026-10-13 — Уведомления: at-least-once
Никакого фиктивного exactly-once для Telegram: дубль возможен только при сбое между отправкой и отметкой.
Участники получают только важное; организатор выбирает «каждый ответ» или «сводку».
