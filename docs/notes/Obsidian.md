# Obsidian — как пользоваться

Хранилище — папка `docs/` репозитория `SashaVas17/soberemsya-tg`. Заметки — обычные `.md` файлы в git:
Claude читает и обновляет их в каждой сессии, вы видите изменения после `pull`.

## Первый запуск (компьютер)
1. Склонируйте репозиторий (GitHub Desktop или `git clone https://github.com/SashaVas17/soberemsya-tg`).
2. Obsidian → «Open folder as vault» → выберите папку **`docs`** внутри репозитория (не корень:
   там `node_modules` и код).
3. Настройки уже лежат в `docs/.obsidian/`: markdown-ссылки, новые заметки — в `inbox/`, вложения — в
   `assets/`, шаблоны — в `templates/`, закладки на главную, ТЗ и идеи.
4. Синхронизация: Settings → Community plugins → Browse → **Git** (автор Vinzent03) → Install → Enable.
   Включите «Pull on startup» и автокоммит раз в 10–15 минут. Пушить можно прямо в `main`:
   изменения только в `docs/` не запускают деплой сайта и функций.

## Телефон
Obsidian Mobile + тот же плагин Git (работает медленнее) или правка файлов прямо на github.com.

## Как работать вместе с Claude
- Идеи и пожелания — в [Идеи](../inbox/Идеи.md) или новой заметкой в `inbox/` (шаблон «Идея»).
  Напишите в чате «посмотри inbox» — Claude разберёт и перенесёт в ТЗ.
- План и статус — только в [ТЗ](../TZ.md); решения — в [журнале](Решения.md).
- Claude обновляет заметки в `notes/` вместе с кодом (новая таблица, маршрут, команда бота).
- Конфликты: перед правкой делайте pull (плагин делает это при запуске).

## Чего здесь не хранить
Токены, ключи, пароли, `initData` — никогда. Только названия переменных, см.
[Настройки и секреты](Настройки-и-секреты.md).
