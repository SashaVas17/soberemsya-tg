# Уведомления

- Очередь `notification_outbox` пополняется в тех же транзакциях, что и изменения встречи.
- `notifications-worker` вызывается pg_cron через pg_net раз в минуту (секрет из Vault
  `notifications_worker_secret`).
- Доставка **at-least-once**: дубль возможен только при сбое между `sendMessage` и отметкой об отправке.
  Это задокументировано, а не замаскировано. 429 → `retry_after`, до 5 повторов, затем `failed`.
- Бот пишет только тем, кто дал разрешение (`requestWriteAccess`, `users.can_message`).

## Типы
| Тип | Кому |
| --- | --- |
| `response_each` / `response_summary` | Организатору: каждый ответ (не чаще 1 в 15 мин) или сводка (по умолчанию) |
| `join_request_new` | Организатору: новая заявка |
| `event_updated`, `event_reopened` | Участникам: встреча изменена |
| `event_decided` | Участникам: выбран итог |
| `event_cancelled` | Участникам: встреча отменена |
| `join_request_approved` / `join_request_rejected` | Автору заявки |
| `reminder_24h`, `reminder_2h` | Напоминания, по выбору пользователя (по умолчанию выключены) |

Каждое сообщение — с кнопкой в нужный экран Mini App. Тон — нейтральный, на «вы».
Код: `_shared/notification-messages.ts`, `_shared/notification-settings.ts`, `notifications-worker/index.ts`.
