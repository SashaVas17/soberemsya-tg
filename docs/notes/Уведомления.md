# Уведомления

- Очередь `notification_outbox` пополняется в тех же транзакциях, что и изменения встречи.
- `notifications-worker` вызывается pg_cron через pg_net раз в минуту (секрет из Vault
  `notifications_worker_secret`).
- Доставка **at-least-once**: дубль возможен только при сбое между `sendMessage` и отметкой об отправке.
  Это задокументировано, а не замаскировано. 429 → `retry_after`, до 5 повторов, затем `failed`.
- Бот пишет только тем, кто дал разрешение (`requestWriteAccess`, `users.can_message`).
- Язык сообщения выбирается при отправке: воркер читает `users.language` / `language_code` получателя (для групп —
  организатора встречи). Не прочитал — отправляет по-русски, но отправляет. Тексты — `renderNotification`
  и `renderGroupMessage` с параметром языка.

## Типы
| Тип | Кому |
| --- | --- |
| `response_each` / `response_summary` | Организатору: каждый ответ (не чаще 1 в 15 мин) или сводка (по умолчанию) |
| `join_request_new` | Организатору: новая заявка |
| `event_updated`, `event_reopened` | Участникам: встреча изменена |
| `event_decided` | Участникам: выбран итог |
| `event_cancelled` | Участникам: встреча отменена |
| `join_request_approved` / `join_request_rejected` | Автору заявки |
| `decide_reminder` | Организатору, один раз на встречу: итог не выбран, а ближайший будущий вариант времени меньше чем через сутки (кнопка «Выбрать итог»). Не для встреч, созданных меньше 3 часов назад, и не тем, у кого уведомления об ответах выключены (`response_mode = 'off'`). Устаревает, когда встреча решена, отменена или удалена. Ставит в очередь `enqueue_decide_reminders` из `enqueue_due_notifications` |
| `reminder_24h`, `reminder_2h` | Напоминания, по выбору пользователя (по умолчанию выключены) |
| `event_repeated` | Участникам прошлой встречи, когда организатор нажал «Собрать ещё раз»: приглашение на новую встречу (кнопка «Выбрать время»). Не получают: кто заблокировал организатора или заблокирован им, кому бот не может писать, гости без аккаунта; не больше 50 человек; от ограниченного организатора — никому. Лимит `event_repeat` — 3 в час, 5 в сутки. Организатору показывается число людей прошлой встречи до этих фильтров: оно не выдаёт, что кто-то его заблокировал |
| `report_new` | Администраторам (`TELEGRAM_ADMIN_IDS`): новая жалоба; кнопка открывает «Жалобы» (`startapp=reports`), не устаревает |

Каждое сообщение — с кнопкой в нужный экран Mini App. Тон — нейтральный, на «вы».
Код: `_shared/notification-messages.ts`, `_shared/notification-settings.ts`, `notifications-worker/index.ts`.
