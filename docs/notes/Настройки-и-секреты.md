# Настройки и секреты

> Здесь только **названия**. Значения секретов никогда не записываются в заметки, репозиторий и чат.

## Supabase Edge Functions (секреты проекта)
`TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`, `TELEGRAM_APP_SHORT_NAME`, `TELEGRAM_WEBHOOK_SECRET`,
`TELEGRAM_MINI_APP_URL`, `TELEGRAM_ADMIN_IDS`, `TELEGRAM_DB_SECRET_KEY`, `TELEGRAM_CALENDAR_SIGNING_SECRET`.
Supabase задаёт `SUPABASE_URL` и служебный ключ сам.

- `TELEGRAM_DB_SECRET_KEY` и `TELEGRAM_CALENDAR_SIGNING_SECRET` не меняются при смене бота.
- `TELEGRAM_DB_SECRET_KEY` — серверный (secret) ключ Supabase, через него функции ходят в базу: самый ценный
  секрет. Что делать при утечке любого секрета — [Безопасность](Безопасность.md#если-секрет-утёк).
- Секрет воркера уведомлений — в Supabase Vault (`notifications_worker_secret`).

## GitHub
- Секрет `SUPABASE_ACCESS_TOKEN` — для `deploy-functions.yml`.
- Переменные `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY` и имя бота/приложения — для `deploy-pages.yml`.

## Фронтенд (`.env`, не коммитится)
`VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`, `VITE_TELEGRAM_BOT_USERNAME`,
`VITE_TELEGRAM_APP_SHORT_NAME`, `VITE_SERVER_FUNCTION_URL`, mock-режим: `VITE_USE_MOCK_TELEGRAM`,
`VITE_USE_MOCK_API`, `VITE_MOCK_INIT_DATA`; необязательные стили карты `VITE_MAP_STYLE_URL`, `VITE_MAP_STYLE_DARK_URL`
(по умолчанию OpenFreeMap, без ключа). Пример — `.env.example`.
