# Дизайн «Закат» (вариант А2, Liquid Glass)

- Фон — размытые пятна: персик, розовый, лавандовый. Стеклянные панели, шапка и плавающее меню.
- Акцент — фиолетовый `#6a3cf0`; тёмная тема — `#b49bff` на `#130a1a`. Тёплый акцент — токеном.
- Шрифты: **Unbounded** (заголовки, цифры дат) и **Golos Text** (текст), из npm `@fontsource-variable`.
- Меню (5 мест): Главная, Открытые, «+», Карта, Мои. «+» — спокойная круглая кнопка внутри панели, ровно
  по центру, без обводки и свечения (решение владельца 2026-10-14). «Карта» пока — экран «скоро» (этап 4).
- Обязательно: тёмная тема (по теме Telegram + переключатель), запасной фон без `backdrop-filter`,
  упрощение при `prefers-reduced-transparency` и на слабых устройствах, контраст не ниже WCAG AA.
- Логотип: надпись `flockly` (Unbounded 700, белая), «o» — светящийся круг `#ffb98e` на `#5b2fe0`.
- Категории: плашки `.category-chip` (40 px, зона нажатия 44 px, выбранная — акцентная заливка), в ленте —
  один прокручиваемый ряд до краёв экрана, в мастере — с переносом; значок `.category-badge` на карточке.
  Иконки категорий — `src/categories.ts` (новая категория без иконки получает общий «ярлык»).
- Иконки — `lucide-react`. Новые иконки подбирать в том же наборе (скилл `better-icons`, префикс `lucide`).
- Полировка интерфейса — скилл `make-interfaces-feel-better` (радиусы, отступы, анимации, зоны нажатия).

Макеты: артефакт «Flock — дизайн и логотип» (ссылка в [ТЗ](../TZ.md)). Файлы стилей —
`src/design-tokens.css`, `src/theme-sunset.css`.

Не сделано из макетов: панель «Ваш выбор» на экране встречи.
