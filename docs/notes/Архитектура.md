# Архитектура

```
Telegram (клиент) ──► Mini App (React + Vite, GitHub Pages)
        │                    │  initData в каждом запросе
        │                    ▼
        │            Edge Function telegram-api ──► PostgreSQL (Supabase)
        │                                             ▲   │ pg_cron
        ▼                                             │   ▼
  Бот @flocklyappbot ──► Edge Function telegram-bot ──┘  pg_net ──► notifications-worker ──► Telegram Bot API
```

- **Фронтенд** — `src/`, React + Vite + TypeScript, деплой на GitHub Pages при мерже в `main`.
  Подробнее — [Mini App](Mini-App.md).
- **Бэкенд** — Supabase Edge Functions в `supabase/functions/`:
  - `telegram-api` — всё API Mini App, проверяет подпись Telegram `initData` на каждом запросе ([API](API.md));
    по команде администратора забирает места из OpenStreetMap (Overpass API, без ключа; данные © участники
    OpenStreetMap, ODbL — атрибуция в приложении);
    карта в Mini App берёт тайлы у OpenFreeMap напрямую из браузера (без ключа);
  - `telegram-bot` — вебхук бота ([Бот](Бот.md));
  - `notifications-worker` — отправка очереди уведомлений ([Уведомления](Уведомления.md)).
  - Общий код — `supabase/functions/_shared/`.
- **База** — PostgreSQL. Браузер в таблицы не ходит: все таблицы с RLS и без прав у `anon`/`authenticated`;
  изменения — атомарные RPC `security definer` с `set search_path = pg_catalog, public`, доступ только
  у `service_role`. Подробнее — [База данных](База-данных.md).
- **Фоновые задачи** — pg_cron; вызов воркера — pg_net с секретом из Vault.

Связанное: [Релизы и деплой](Релизы-и-деплой.md), [Настройки и секреты](Настройки-и-секреты.md).
