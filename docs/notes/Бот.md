# Бот @flocklyappbot

Вебхук — Edge Function `telegram-bot`. Short name Mini App — `app`.

## Команды
| Команда | Что делает |
| --- | --- |
| `/start` | Кнопка «Открыть Flockly» |
| `/new` | В личке — кнопка «Создать встречу». В группе — ссылка на 24 часа только для отправителя; созданная встреча привязывается к группе, в группу уходят карточка и итог |
| `/my` | Кнопка «Мои встречи» |
| `/help` | Короткая справка |
| `/stats` | Статистика, отвечает только администратору (`TELEGRAM_ADMIN_IDS`) |

## Группы и чаты
- В группах бот видит только команды (privacy mode). В группу публикует только карточку встречи и итог.
- Карточка встречи отправляется из приложения через `savePreparedInlineMessage` + `WebApp.shareMessage`;
  запасной путь — обычная ссылка. Inline-режим бота включён.

## Язык
- Ответы бота — на языке человека: выбор в настройках приложения (`users.language`), иначе язык его Telegram
  (`from.language_code`): русский для СНГ, английский для остальных. Ответы на команды в группе — на языке
  отправителя, карточка и итог в группе — на языке организатора.
- Меню команд: английское по умолчанию и русское для ru/be/uk/kk/ky/uz/tg/tk/hy/az (`setMyCommands` с
  `language_code`). Кнопка меню «Открыть Flockly» одна на всех (у Telegram нет её перевода).
- `/stats` — только для администратора, по-русски.

## Настройка
- Вебхук, команды и кнопка меню — скрипт `scripts/configure-telegram.sh` (Mac/Linux) или
  `scripts/configure-telegram.ps1` (Windows). Запускает владелец, секреты вводятся скрыто.
- Урок переезда (2026-10-13): секрет вебхука в Supabase и в `setWebhook` должен совпадать до символа,
  иначе 401.
- Аватарка и описание — через BotFather (вручную).
