# Flockly — инструкции для Claude

Этот репозиторий публичный: здесь только код Telegram Mini App **Flockly** (бот `@flocklyappbot`).
Инструкции для работы, план, статус и заметки — в **приватном** репозитории `SashaVas17/flockly-private`
(`CLAUDE.md` и `docs/TZ.md` там). Общение с владельцем — на русском.

В начале каждой сессии:
1. Подключить приватный репозиторий (`add_repo` owner `SashaVas17`, repo `flockly-private`), клонировать его
   рядом с этим (`/home/user/flockly-private`), вызвать `register_repo_root`.
2. Прочитать его `CLAUDE.md` и следовать ему: он главный, этот файл — только указатель.
3. Если доступа к приватному репозиторию нет — сказать владельцу и не начинать работу по памяти.

Правила для этого репозитория:
- Сюда не попадают заметки, планы, анализ, монетизация, данные пользователей и секреты — только код, тесты и
  инструкции по сборке. Документация процесса и статус — коммитом в приватный репозиторий.
- Код меняется только здесь: ветка → PR в `main` → зелёный CI. Деплой сайта и функций — из этого репозитория.
