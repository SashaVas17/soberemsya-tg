# Security policy

Flockly is a Telegram Mini App. If you find a vulnerability, please report it privately through
**GitHub → Security → Report a vulnerability** in this repository. Do not open a public issue and do not
test against other people's data or accounts.

Please include what is affected, how to reproduce it, and the impact you expect. You will get an answer
in Russian or English.

---

Если вы нашли уязвимость, сообщите о ней приватно: **GitHub → Security → Report a vulnerability** в этом
репозитории. Не создавайте публичный issue и не проверяйте уязвимость на чужих данных или аккаунтах.
